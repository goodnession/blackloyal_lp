# BlackLoyal Landing Page

Лендинг для геймифицированной системы лояльности компьютерных клубов.

## Документация

Вся документация находится в [index.md](./index.md)

## Быстрый старт

### Локальная разработка

```bash
cd frontend
cp .env.example .env.development
yarn install
yarn dev
```

### Деплой

См. раздел [Деплой](./index.md#деплой) в документации.

## Технологический стек

- Nuxt 3 + Vue 3 + TypeScript
- Tailwind CSS
- Docker + Traefik
- Terraform (Timeweb Cloud)
- GitHub Actions
